# 펜 위치·저장 색상 수정 — 2026-10-14

대상 소스: **EmberPDF 0.9.0 (build 69) Developer Preview**

사용자 증상은 마우스·펜을 놓은 뒤 획 위치가 바뀌고, PDF 글자 위에 그린 획이 보이지 않거나 글자를 가리는 현상입니다.

## 변경

- 압력 펜·연필·만년필·형광펜의 사용자 정의 주석에서 `PDFPage.transform(for:)`를 적용합니다. 입력 좌표는 회전 전 PDF 페이지 좌표인데, `PDFAnnotation.draw`에 전달되는 문맥은 표시 영역의 좌표입니다. 이 변환이 누락되어 페이지 기준점·CropBox·회전에 따라 확정된 획이 이동했습니다. 일반 불투명 펜의 네이티브 Ink 경로는 유지합니다.
- 연필은 색을 포함하는 작은 벡터 패턴으로 저장합니다. 기존 무색 패턴을 PDFKit이 기록하면서 패턴 내부에 검정색 명령을 넣어 바깥의 지정 색이 사라졌습니다. 8×8 셀·144개 질감 점·좌표에 고정된 질감과 불투명도는 유지합니다.
- 형광펜은 완성한 획 전체를 Multiply로 합성합니다. 검정 글자는 유지하고 흰 종이와 유색 배경에 선택한 색을 입힙니다. 일반 펜은 Normal 합성을 유지하여 글자 위에서도 획이 보이게 합니다.
- 저장 시 중간 투명 레이어에 붙는 Generic RGB 색상 변환을 없앴습니다. 이 변환은 파란 획에 초록 성분을 더했습니다. 반투명 펜·만년필과 형광펜은 획의 외곽을 모아 한 번 채우고, 연필은 질감 패턴을 한 번 채워 교차점에서도 불투명도가 중첩되지 않도록 합니다. 불투명 일반 펜·만년필은 기존의 가벼운 선분 그리기를 유지합니다.

전체 페이지를 이미지로 변환하거나 필기 중 문서를 저장하지 않습니다. 기존 저장 파일을 자동으로 수정하는 마이그레이션도 하지 않습니다.

## 검증

관련 XCTest **93개 통과, 실패 0**. 로그는 `work/ink69/regression-tests-final.log`입니다. 프로젝트 정적 검사와 10개 언어 키 일치 검사도 통과했습니다(`work/ink69/static-validation.log`). 이번 변경의 검사 수이며 이전 빌드 결과와 합산하지 않습니다.

- `PDFInkAnnotationGeometryTests`: 원점이 다른 MediaBox·CropBox, 0/90/180/270도 회전, 일반 펜·압력 펜·연필·만년필·형광펜의 실시간 렌더링과 저장 후 재열기. 독립적으로 그린 PDF의 위치 표식을 기준으로 비교합니다.
- `PDFInkPointerInteractionTests`: 실제 마우스 이벤트로 그린 뒤 마우스를 놓기 전후 위치·크기를 비교하고 실행 취소·다시 실행을 확인합니다. 회전·확대·자른 페이지를 포함합니다.
- `PDFInkCompositingTests`: 검정 본문·흰 종이·유색 배경 위의 펜과 형광펜, 빨간색·파란색 연필의 저장 전후 색·질감, 파란색·노란색 형광펜의 합성, 교차점의 단일 불투명도와 연필 질감 전체에 적용한 불투명도를 비교합니다.
- 기존 필기 종류·부분 지우기·복사·페이지 추출·지우개 제스처·모드 정책·읽기 색상 검사를 포함합니다.
- 회전된 페이지의 드래그 중 캡처와 확정 후 렌더링을 시각적으로 비교했습니다. 위치·색상 증거 PDF와 PNG는 `work/ink69/final/`에 보관합니다.

오프스크린 `cacheDisplay`는 PDFKit 네이티브 주석 레이어를 포함하지 않으므로, 포인터 검사는 실제 미리보기 캡처와 같은 화면 위치로 렌더링한 확정 페이지를 비교합니다. 디스플레이 색상 프로필 차이를 감안해 색상 우세로 획 영역을 찾되 위치·크기 오차는 픽셀 단위로 제한합니다. 실제 태블릿·Sidecar 하드웨어나 사용자 원본 PDF에서의 수동 검증은 하지 않았습니다.
