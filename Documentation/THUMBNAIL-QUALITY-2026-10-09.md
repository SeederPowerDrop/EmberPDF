# EmberPDF 0.9.0 build 38 — 썸네일 선명도

기준일: 2026-10-09. 사이드바와 페이지 개요의 미리보기 렌더링을 수정한다. 앞선 [build 37 PDF 비교 배치·이동](PDF-COMPARISON-2026-10-09.md)의 기능과 검증 결과는 해당 기록에 보존한다.

## 원인과 수정 범위

사이드바는 논리적 표시 폭을 기준으로 이미지를 요청하면서 Retina 화면의 픽셀 배율을 반영하지 않았고, 효율적 렌더링 모드에서는 그 폭의 80%로 더 줄였다. 이 작은 비트맵을 실제 화면 폭으로 확대하면서 글자가 흐려졌다. 페이지 개요에는 폭을 직접 2배로 보내는 별도 보정이 있어 같은 미리보기 구성요소에서도 호출 위치에 따라 해상도 계산이 달랐다.

`PageThumbnailView`의 폭은 화면의 논리적 포인트(pt)로 통일한다. 공통 `PDFThumbnailRenderingPolicy`가 전달받은 `displayScale`을 적용해 실제 렌더링 픽셀 크기를 계산하고, 효율적 모드의 80% 축소는 제거한다. 페이지 개요는 수동 `×2` 보정을 제거하고 같은 경로를 사용한다.

렌더링 요청 식별자에는 폭과 화면 배율을 함께 넣는다. 창을 배율이 다른 화면으로 옮기거나 패널 크기를 바꾸면 새 해상도의 이미지를 요청하며, 같은 페이지의 이전 이미지는 새 렌더링이 준비될 때까지 유지한다. 문서 수정·회전 등 내용 식별자가 달라진 경우에는 이전 내용을 재사용하지 않는다.

## 메모리와 렌더링 수명

선명도 수정은 미리보기의 화면 배율 계산에 한정한다. 기존 크기·메모리 제한은 유지한다.

| 설정 | 이미지 최대 변 길이 | 이미지 최대 픽셀 수 | 캐시 메모리 상한 | 캐시 항목 수 상한 |
|---|---:|---:|---:|---:|
| 효율적 렌더링 켬 | 1,600px | 2,400,000 | 72 MiB | 80 |
| 효율적 렌더링 끔 | 2,400px | 5,000,000 | 144 MiB | 144 |

이 상한은 요청한 표시 크기보다 우선하므로 큰 미리보기에서는 해상도가 제한될 수 있다. 빠른 스크롤이나 연속 크기 변경 중 일시적인 요청을 취소하는 35ms 대기, 실제 픽셀 크기를 포함한 캐시 키, 메모리 압력 때 재생성 가능한 캐시를 비우는 동작도 유지한다. 캐시 상한은 앱 전체 메모리의 상한을 뜻하지 않는다.

PDF 본문·주석·저장 파일의 내용이나 해상도를 바꾸지 않으며, 새 OCR을 수행하지 않는다.

## 검증 결과

- 관련 자동 검사 **104개 통과, 실패 0**. 로그: `work/thumbnail-build38/tests-final.log`.
- 신규 실제 PDFKit 비트맵 검사 5개: 320pt에서 1x/2x 픽셀 수, 배율별 캐시 분리와 재사용, 페이지 회전, 300% 확대의 픽셀 상한, 비정상 배율·기하 입력. 효율적 렌더링 켬/끔을 모두 검사했다.
- 별도 합성 벡터 PDF에서 기존 320pt 미리보기는 **256×331px**, 수정된 Retina 요청은 **640×828px**로 생성됨을 확인했다. PDFKit 자체가 화면 배율을 자동 적용하지 않으므로 호출부에서 배율을 전달해야 한다.
- 갤러리 검색 미리보기 검사는 고해상도 요청에서 기존 예상 좌표 계산의 문제가 드러났다. Core Graphics 변환을 1×1로 정규화한 후 실제 픽셀 크기로 확대하도록 시험의 예상값 계산을 보정했다. 제품의 좌표 변환과 오차 허용치는 바꾸지 않았다. 네 회전 방향의 실제 강조 픽셀 검사도 통과했다.
- 별도 식별자의 QA 앱에서 한국어·영어 벡터 글자가 있는 합성 PDF를 열고, 세로 사이드바 100%→200%→300% 및 상단 가로 사이드바 300%의 선명한 글자를 확인했다. QA 앱은 종료했다. 사용자의 PDF와 본 앱 환경설정은 변경하지 않았다.
- 페이지 개요·갤러리·읽기 색상·사이드바 배치/키보드·메모리 정책 관련 회귀 검사와 정적 검사 통과. 정적 검사에서 버전 38, macOS 14.0+, 10개 언어 일치를 확인했다. 로그: `work/thumbnail-build38/static.log`.
- 소스 전체의 공백 검사 통과. build 37 결과는 이번 검사 수에 합산하지 않았다.
