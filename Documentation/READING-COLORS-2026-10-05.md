# 읽기 색상과 EmberPDF의 제작 이야기 — 2026-10-05

대상: **EmberPDF 0.9.0 (build 24) Developer Preview**. 앱의 화면과 PDF 종이의 색을 함께 고를 수 있는 읽기 설정과 앱 정보의 제작 이야기를 추가한다. [build 23 갤러리 기록](OPEN-PDF-GALLERY-2026-10-05.md), [build 22 디자인 기록](EMBER-DESIGN-2026-10-05.md)과 [페이지 번역 기록](PAGE-TRANSLATION-2026-10-05.md)은 각각 당시 검증 결과로 보존한다.

## 사용법

**설정 → 읽기 색상**, **보기 → 읽기 색상**, 또는 문서 읽기 도구줄의 읽기 색상 버튼에서 선택한다. 설정과 도구줄 팝오버에는 종이 색상 견본, 짧은 읽기 미리보기와 선택한 색상의 설명을 함께 표시한다. 선택은 다음 실행에도 유지한다.

| 선택 | PDF 종이 | 앱 화면 |
| --- | --- | --- |
| 원본 색상 | 원래 PDF의 색을 그대로 표시 | 기존 시스템·라이트·다크 선택 사용 |
| 부드러운 종이 | 흰색을 은은한 미색으로 낮춤 | 기본 화면 모드를 따르는 부드러운 표면 색 |
| 따뜻한 종이 | 흰색을 따뜻한 종이 색으로 조절 | 기본 화면 모드를 따르는 따뜻한 표면 색 |
| 밤 읽기 | 흰색을 차분한 회색으로 낮춤 | 일시적으로 어두운 화면 사용 |

읽기 색상은 기존 **화면 모드**와 별도의 설정이다. 밤 읽기에서 어두운 화면을 쓰더라도 사용자가 저장한 시스템·라이트·다크 선택을 덮어쓰지 않는다. 다른 읽기 색상으로 바꾸면 그 화면 모드가 다시 적용된다. 원본 색상은 색을 정확하게 비교하거나 확인할 때도 바로 선택할 수 있다.

이 기능은 밝기와 색감에 대한 사용자 선택을 제공하며, 건강 개선이나 눈의 피로 감소를 보장하는 기능으로 설명하지 않는다.

## 화면 표시와 원본 보존

- 검은 글자는 어둡게 유지하며 밝은 종이에 양의 RGB 배율을 적용한다. 글자와 종이의 명암을 반대로 뒤집거나 사진을 음화로 반전하지 않는다.
- 페이지 전체에 표시 효과를 적용하므로 그림·사진·주석의 화면 색도 함께 달라진다. 페이지에서 흰 종이 영역만 인식해 바꾸는 처리는 아니다. 이 범위는 색상 선택 화면에 설명한다.
- PDFKit 읽기 화면, PDF 같이 보기, 번역 페이지 미리보기와 페이지·갤러리 미리보기가 같은 읽기 색상 설정을 사용한다. 앱의 탭·도구줄·패널·설정·정보 창도 같은 테마에 맞춰 반응한다.
- 설정 변경은 `PDFDocument`, 페이지, 주석, 편집 revision이나 dirty 상태를 바꾸는 편집 작업이 아니다. 원본 파일, 저장한 PDF, PDF·이미지·Office 내보내기 결과에는 읽기 색상 효과를 굽지 않는다.
- 썸네일과 갤러리의 공유 래스터 캐시는 원래 색상을 보관한다. 표시 시점에만 색을 합성하므로 읽기 색상을 바꾸기 위해 모든 페이지를 다시 렌더링하거나 휴면 문서를 재개하지 않는다.

## 구현 경계

`PDFReadingTheme`은 원본 색상·부드러운 종이·따뜻한 종이·밤 읽기와 `preferences.readingTheme` 저장 키를 정의한다. `AppPreferences`가 선택을 보관하며 `EmberTheme`과 `HwattakPDFTheme`이 앱 표면 색에 반영한다. 밤 읽기의 네이티브 어두운 외관은 저장된 기본 화면 모드와 분리한다.

`PDFReadingDisplayFilterController`는 PDFKit이 현재 보여 주는 제한된 뷰포트에 `CIColorMatrix` 표시 필터를 적용한다. 수천 페이지가 들어갈 수 있는 전체 문서 뷰에 필터를 걸지 않으며, 해당 컨트롤러가 추가한 필터만 제거한다. 종이 색은 선형 RGB 작업 공간을 고려하고, PDFKit의 페이지 주변 배경은 앱의 캔버스와 맞도록 보정한다.

SwiftUI 썸네일·갤러리 이미지는 `pdfReadingAppearance()`의 표시 합성을 사용한다. 읽기 색상은 래스터 캐시 키나 원본 문서 저장 경로에 들어가지 않는다. 확대·이동·선택·편집은 기존 PDFKit 흐름을 유지한다.

## 앱 정보의 이야기

앱 정보는 다섯 문단으로 다음 뜻을 전한다.

1. PDF를 다룰 때 느낀 불편함에 화가 나서 만든 앱이라 처음에는 **HwattakPDF**라는 이름을 붙였다.
2. 그 분노는 이제 누구나 PDF를 편리하고 편안하게 다루도록 돕는 힘이 되었다.
3. **잉걸불**이 오래 온기를 품듯 사용자 곁을 오래 지키는 도구가 되길 바라며 **EmberPDF**라는 이름으로 새롭게 시작한다.
4. 구독료와 광고 없이 무료로 제공하며 자발적인 후원으로 개발·유지보수를 이어 간다.
5. 읽기부터 편집까지 매일의 문서 작업을 차분하게 돕는 앱으로 가꾸어 간다.

앱 정보와 읽기 색상 문구는 지원하는 10개 언어에 제공한다. 기존 소개 그림·외부 링크·후원 동작은 유지하며, 시작 화면 이름에 숨겨 둔 제작 계기 이스터에그도 유지한다. 앱 정보 본문은 기존 스크롤 영역을 사용한다.
