# 메모 연결 검색·모양·숨김 — build 36

EmberPDF 0.9.0 build 36의 로컬 변경입니다. 공개 GitHub Release는 포함하지 않습니다.

## 연결 대상 찾기

- 연결 창에서 열린 PDF를 선택하고 **현재 읽는 N페이지에 바로 연결**을 누릅니다. 입력한 페이지나 검색 결과와 독립적으로, 버튼을 누를 때 대상 PDF에서 읽고 있는 위치를 사용합니다.
- **본문 검색**에서 선택한 PDF의 본문·OCR 텍스트를 검색하고 페이지별 미리보기를 골라 연결합니다. 현재 페이지부터 문서 끝, 다시 처음 순서로 검색하며 최대 200개 결과 페이지를 제공합니다.
- 검색은 기존 PDF 검색어·선택·읽는 위치와 원본 탭을 바꾸지 않습니다. 검색어 변경, 창 닫기, 문서 수정에는 기존 작업을 취소하고 이전 결과를 사용하지 않습니다.
- 이미지뿐인 PDF는 OCR 안내를 표시합니다. 자동 OCR이나 네트워크 요청은 하지 않습니다. 복사 제한 PDF는 본문 미리보기 검색을 제한합니다.
- 연결 목록은 이 Mac의 EmberPDF에 저장됩니다. 메모 식별자가 추가된 PDF는 저장해야 재열기 후에도 연결이 유지됩니다.

## 메모 모양

- 시스템 색상 창 대신 팝오버 내부 색상표·HEX·RGB를 사용합니다. 배경/글자 색상을 바꾸고 배경 불투명도를 조절하면 같은 화면에서 미리 볼 수 있습니다. **적용**으로 PDF에 반영하고 실행 취소할 수 있습니다.
- PDFKit이 글자 색상을 보정 색 공간으로 변환하면서 빨강 등이 달라지는 현상을 확인했습니다. 원래 sRGB 값과 당시 표준 글자 모양 값을 함께 보관하여 보존합니다. 다른 편집기에서 표준 값을 바꾸면 외부 변경을 우선합니다.
- 투명 배경은 PDF의 벡터 모양에 저장되어 다시 열어도 유지됩니다. 적용 실패 시 안내를 표시합니다. 크기·위치 조절, 연결 식별자와 주석 플래그를 유지합니다.

## 메모 표시·숨김

- 메모 행의 눈 아이콘은 해당 메모를 숨기거나 표시합니다. 목록 상단의 **메모 표시** 메뉴는 전체 숨기기/표시를 제공합니다. 숨긴 메모는 목록에 표시와 개수로 남습니다.
- 숨김은 FreeText 메모에만 적용합니다. 하이라이트와 펜 자국은 변경하지 않습니다. 숨긴 메모는 PDF 위에서 드래그하거나 지우개로 지울 수 없고 목록에서는 읽고 수정할 수 있습니다.
- 표준 PDF NoView 플래그를 사용하므로 PDF 저장 시 숨김 상태가 유지됩니다. 화면 표시만 바꾸며 기존 인쇄 플래그와 다른 주석 속성은 보존합니다. 전체 숨김도 한 번의 실행 취소로 원래 상태를 복원합니다.
- 목록을 읽는 동안 전체 작업은 비활성화합니다. 변경된 메모, 다른 문서 메모, 저장 전 작성 초안, 편집 권한이 없는 상태에서는 적용하지 않습니다.
