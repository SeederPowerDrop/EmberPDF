# 학습 메모 편집·연결과 펜 종류 — build 34

요청일: 2026-10-08. 구현·검증은 10월 9일까지 진행했습니다. EmberPDF 0.9.0 build 34의 로컬 변경이며 GitHub Release 공개는 포함하지 않습니다.

## 사용할 수 있는 기능

- **학습 노트 → 새 메모/메모 수정**은 오른쪽 패널에서 작성합니다. **별도 창으로** 누르면 이동·크기 조절 가능한 창이 되고 **옆에 붙이기**로 복귀합니다. 창의 닫기는 초안을 버리지 않고 패널에 붙입니다. 적용 전 초안은 PDF를 변경하지 않으며 탭 전환에도 유지합니다.
- 메모 행의 **메모 모양**에서 배경/글자 색상, 배경 불투명도 0–100%, 글자 크기, 너비·높이·위치를 조절합니다. **페이지에서 이동·크기 조절**로 메모를 고르고 본체/모서리를 드래그합니다. 글자는 배경과 별도로 불투명하게 유지합니다. 위치·스타일·내용 변경은 실행 취소할 수 있습니다.
- 새 메모 폭은 내용에 맞춰 140–280pt, 높이는 최소 32pt부터 정합니다. 긴 메모는 높이도 늘어나되 페이지 안에 제한되고 목록/편집창에서 전체 내용을 읽을 수 있습니다. 기존 메모의 내용 수정은 사용자가 조절한 크기를 보존합니다. 이전 검은 글씨·투명 배경 메모의 가독성 복구는 새 스타일 설정이 없는 경우에만 적용합니다.
- 펜 설정에서 **잉크·연필·만년필·형광펜**을 선택합니다. 연필은 미세한 질감, 만년필은 방향·필압에 따른 굵기, 형광펜은 넓은 반투명 획을 사용합니다. 각각 굵기와 불투명도를 다시 조절할 수 있습니다. 필압은 지원 입력 장치가 보내는 값만 사용합니다. 설정 미리보기와 실제 필기는 같은 렌더러로 그립니다.
- 메모 목록의 **연결**에서 열린 PDF의 페이지/메모를 연결합니다. 페이지 연결은 목록 상단, 메모 연결은 해당 행의 연결 버튼에서 관리합니다. 양쪽에서 상대 위치로 이동하며 연결 삭제와 파일 다시 연결을 제공합니다.

## 저장 및 연결 범위

메모 자체는 PDF FreeText 주석입니다. 기본 PDFKit의 FreeText 배경 색상은 저장 과정에서 alpha를 버리므로 별도 appearance를 사용하고 배경 투명도 메타데이터를 보존합니다. 저장·재열기 후의 실제 PDF 렌더를 검사했습니다. 조절 핸들은 PDF에 저장되지 않습니다.

연결 목록은 **이 Mac의 EmberPDF에 저장**됩니다. PDF를 다른 앱이나 기기로 보내면 이 관계 목록이 포함되지는 않습니다. 링크는 사용자가 누를 때만 열고, 이미 열린 탭을 재사용하거나 보안 북마크를 통해 엽니다. 북마크 복원이 실패하면 파일을 다시 선택해야 하며 저장된 경로를 권한 우회에 사용하지 않습니다.

PDFKit가 표준 `/NM`을 버리는 경우가 있어 메모 연결에는 별도의 `/EmberPDFNoteID`를 사용합니다. 식별자가 없는 기존 메모를 연결할 때에는 수정 권한을 확인하고 되돌릴 수 있는 메타데이터 편집을 등록합니다. 이때 PDF도 저장해야 다시 열어도 같은 메모를 찾을 수 있습니다. 식별자가 중복되거나 메모가 삭제되면 다른 메모로 추정해 이동하지 않습니다.

연결은 현재 페이지 번호를 기준으로 합니다. 연결 후 페이지를 삽입·삭제·재정렬하면 기존 위치를 다시 연결해야 할 수 있습니다. 메모를 찾지 못하면 해당 페이지를 열고 안내합니다. 네트워크 동기화나 외부 PDF 리더용 표준 링크 생성은 이 빌드의 범위가 아닙니다.

## 성능 변경과 측정

1. 메모 목록은 문서당 페이지별 캐시를 유지합니다. 최초 읽기는 페이지마다 실행을 양보하고, 추가·내용·스타일·기하 변경 및 실행 취소/다시 실행은 영향을 받은 페이지만 갱신합니다. 구조 변경처럼 영향 범위를 모르면 전체를 다시 읽습니다. 문서를 닫거나 교체하면 캐시를 비웁니다.
2. 초안 텍스트는 별도의 observable object로 관리합니다. 100회 입력 업데이트에서 workspace 전체 발행 0회, PDF 주석 변경 0회인 것을 검사했습니다. 80쪽 문서의 메모 추가/Undo/Redo는 각각 1쪽만 다시 읽습니다.
3. 자동 복구 저장은 메인 스레드에서 독립 PDF 복사본을 만든 뒤 직렬 백그라운드 작업으로 기록합니다. PDFKit의 얕게 남는 delegate·페이지 목적지·outline과 앱 주석 복사 경계를 분리합니다. 파일 세대 작성과 복구 목록 공개를 나누고, 완료 시 문서·revision·dirty·취소·설정 상태를 다시 검사합니다. 저장하거나 닫은 뒤 오래된 작업이 복구 기록을 되살리지 않습니다.

읽기 전용으로 조사한 428쪽, 약 40MiB 책에서 기존 전체 직렬화는 **6.192초**였습니다. 복사본/참조 분리 준비는 **0.175초**, 배경 저장은 **4.179초**였으며 그동안 메인 스레드의 50ms 응답 확인이 79회 진행했습니다. 이 값은 해당 파일의 로컬 측정이며 모든 PDF에 대한 속도 보장은 아닙니다. 원본 책은 수정하지 않았습니다.
