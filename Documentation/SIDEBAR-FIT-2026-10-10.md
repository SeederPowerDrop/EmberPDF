# 페이지 패널 자동 맞춤·함께 보기 설정 — 2026-10-10

대상: EmberPDF 0.9.0 (build 44), macOS arm64.

## 변경

- 함께 보기 설정의 배치 버튼을 같은 폭으로 펼치고, 문서 위치 동기 이동 카드를 가용 폭에 맞춘다. 바깥 여백과 설명 간격을 줄인다.
- 페이지 썸네일의 배율(50–300%)·묶음 방식을 기준으로 좌우 패널 폭 또는 상하 패널 높이를 자동 계산한다. 상하 패널은 문서 첫 페이지의 방향·비율을 안정적인 기준으로 사용하고 각 묶음은 자체 페이지 비율로 맞춘다. 전체 문서를 스캔하지 않는다.
- 자동 맞춤 뒤 경계선 드래그·방향키·접근성 조절로 수동 크기를 지정할 수 있다. 폭·높이를 별도로 기억한다. 배율 또는 묶음을 다시 바꾸면 자동 맞춤으로 돌아간다.
- 하드 최소 크기는 좌우 124pt, 상하 112pt로 낮추고, 썸네일·번호가 패널 안에 들어가도록 맞춘다. 큰 배율에서도 본문 최소 공간과 창 크기를 우선한다.
- 좁은 헤더에서는 페이지·검색 버튼을 아이콘으로 표시한다. 상하 패널 제어 영역을 174→146pt로 줄이고 편집 모드 드롭 영역도 패널 높이에 맞춘다.
- 검색 패널은 별도 크기를 기억하고 기존 250pt 폭·210pt 높이 최소값을 유지한다. 검색 조절이 페이지 패널의 수동 크기를 덮어쓰지 않는다.
- 슬라이더·핀치 중에는 썸네일만 로컬 미리보기로 바꾸고, 배율 저장과 패널 자동 맞춤은 조절 종료 때 반영한다. 팝오버 위치와 기존 렌더링 지연 정책을 유지한다.
