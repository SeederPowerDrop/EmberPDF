# EmberPDF 0.9.0 build 39 — 함께 보기

작업 시작: 2026-10-09. 검증 및 설치 완료: 2026-10-10. 보기 모드에서의 직접 진입과 드래그 배치 조작을 개선한다. 앞선 build 37의 비교 모델·동기화와 build 38의 미리보기 해상도 수정은 유지한다.

## 변경

- 보기 모드의 기본 도구줄에 **함께 보기** 버튼을 노출한다. 도구를 접어도 보이며, PDF가 두 개 이상 열려 있을 때 활성화된다. 화면 배치 팝오버 안의 기존 진입점과 탭 줄의 중복 버튼은 제거했다.
- 두 장의 문서를 겹친 전용 벡터 아이콘을 버튼·문서 선택 화면·함께 보기 도구줄에서 사용한다. 지원 언어 10개의 명칭과 도움말도 갱신했다.
- **배치 편집**을 켜면 문서 본문 영역을 끌 수 있다. 다른 문서의 왼쪽·오른쪽·위·아래 가장자리에 놓으면 분할하고, 가운데에 놓으면 자리를 바꾼다. 다섯 위치의 안내와 배치 미리보기를 표시한다. 일반 읽기 중에는 제목의 이동 손잡이를 끌어 같은 조작을 할 수 있다.
- **배치 완료** 또는 Escape로 배치 편집을 마친다. 배치 편집 중 Escape는 함께 보기 자체를 종료하지 않는다. 취소된 드래그의 늦은 이벤트가 배치를 바꾸지 않도록 세션을 구분한다.
- 최대 네 문서, 가로·세로 혼합 분할, 분할선 크기 조절, 페이지와 고정 상태를 유지한다. 분할선 드래그는 공통 캔버스 좌표를 사용한다. 일반 읽기에는 본문 드래그용 덮개를 제거한다.

### 실제 앱 조작

별도 식별자의 QA 앱과 자체 생성한 A–E PDF 다섯 개로 확인했다. 사용자 PDF는 변경하지 않았다.

- 도구가 접힌 보기 화면에서도 함께 보기 버튼이 보이고 문서 선택 화면이 열린다.
- 네 문서 선택 시 다섯 번째 문서는 비활성화된다.
- 모든 문서를 3페이지로 이동한 다음 A를 고정했다.
- 배치 편집에서 본문을 끌어 A/B 자리를 교환하고, C를 A 아래에 놓은 뒤 D를 C 오른쪽에 놓았다. 왼쪽 B / 오른쪽 위 A / 오른쪽 아래 C·D의 혼합 배치를 확인했다.
- Escape로 배치 편집만 종료되는 것을 확인했다. 읽기 상태에서 제목을 끌어 C/D 자리 교환도 확인했다.
- 위 배치 전후 네 문서의 3페이지와 A의 고정 상태가 유지됐다.
- 드래그 도중 Escape 후 늦게 들어오는 이벤트는 자동 검사로 확인했다. 해당 키 조합을 실제 마우스 드래그 도중에 누르는 조작은 별도로 재현하지 않았다.
