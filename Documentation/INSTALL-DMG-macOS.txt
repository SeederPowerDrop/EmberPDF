EmberPDF 0.9.0 (build 58) — macOS 설치 안내

지원 환경: Apple Silicon Mac, macOS 14 이상
배포 파일: EmberPDF-0.9.0-build58-macOS-arm64.dmg

이 배포본은 개발용 ad-hoc 서명이며 Apple Developer ID 서명과 공증을
받지 않았습니다. DMG로 포장해도 이 상태는 바뀌지 않으며, 다른 Mac에서
경고 없이 실행되거나 정상 실행된다고 보장할 수 없습니다.

설치하기

1. 배포 출처와 파일을 확인하고 DMG를 두 번 클릭합니다.
2. 기존 EmberPDF 또는 HwattakPDF가 실행 중이면 열린 문서를 저장하고
   ⌘Q로 앱을 종료합니다. 창만 닫는 것으로는 앱이 종료되지 않습니다.
3. DMG 안의 EmberPDF.app을 Applications 바로가기로 드래그합니다.
   기존 앱 교체를 묻는 경우, 앱이 종료된 것을 확인한 뒤 교체합니다.
4. Finder의 응용 프로그램 폴더에서 EmberPDF를 실행합니다.
   실행이 확인되면 Finder 사이드바에서 EmberPDF DMG를 추출합니다.

첫 실행 경고에 대응하기

• 인터넷에서 다운로드한 앱을 열지 묻는 일반 확인창:
  앱 이름과 다운로드 출처를 확인한 뒤 열기를 선택합니다.

• 개발자를 확인할 수 없거나 Apple이 악성 소프트웨어를 확인할 수 없다는 경고:
  출처를 신뢰하고 체크섬을 확인한 본인이 실행하기로 판단한 경우에만,
  응용 프로그램 폴더의 앱을 한 번 열어 본 뒤 다음 순서로 진행합니다.
  시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기(Open Anyway) → 열기
  macOS가 요청하면 Mac 로그인 암호로 승인합니다.
  회사·학교 관리 Mac에서 버튼이 없거나 변경할 수 없으면 관리자에게 문의합니다.

• 앱이 손상되었거나 컴퓨터를 손상시킨다는 경고:
  위의 개발자 확인 경고와 다르게 취급해야 합니다. 강제로 실행하지 마세요.
  배포 출처에서 다시 다운로드하고 체크섬을 비교한 뒤, 경고 문구와 macOS
  버전을 개발자에게 알려 주세요. 체크섬이 같아도 이 경고를 무시하지 마세요.

Apple 공식 안내(경고별 설명과 최신 절차):
https://support.apple.com/ko-kr/102445

체크섬 확인하기(선택: 터미널 사용)

DMG와 함께 제공된 .sha256 파일을 같은 폴더에 두고,
터미널에서 그 폴더로 이동한 다음 아래 명령을 실행합니다.

shasum -a 256 -c EmberPDF-0.9.0-build58-macOS-arm64.dmg.sha256

해당 DMG 이름 뒤에 OK가 나오는지 확인합니다. FAILED 또는 파일을 찾을 수
없다는 메시지가 나오면 설치를 진행하지 말고 파일과 위치를 다시 확인하세요.
체크섬 일치는 제공된 값과 파일이 같다는 뜻이며, Apple 공증을 뜻하지 않습니다.

English summary

Requires Apple Silicon and macOS 14 or later. This build is ad-hoc signed and
not notarized. A DMG does not remove those limitations or guarantee launch on
another Mac.

Open the DMG. Save documents and quit the existing app with Command-Q, then drag
EmberPDF.app to Applications. Launch it from Applications and eject the DMG.

For an unidentified-developer or cannot-check-for-malware warning, only if you
trust the source and have verified the checksum: try opening the installed app,
then choose System Settings > Privacy & Security > Open Anyway > Open. Approve
with your Mac login password if asked. Contact IT if these controls are managed.

Do not force-open an app reported as damaged or harmful. Download it again,
verify the checksum, and share the exact warning with the developer.
The optional checksum command above requires the DMG and .sha256 in one folder.
