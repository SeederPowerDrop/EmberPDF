# 학습 메모와 필기 개선 — 2026-10-08

대상: EmberPDF 0.9.0 build 33. PDF를 읽으며 글자를 선택하고 메모·필기를 만드는 흐름을 개선한다. Flexcil의 모든 기능을 복제하는 범위는 아니다.

## 변경

- 페이지 패널 미리보기 크기: 50–300%, 현재 배율을 누르면 100%. 패널 크기를 조절할 때도 확대된 썸네일이 이전 상한에 잘리지 않는다.
- 학습 노트: 오른쪽 목록에서 PDF FreeText 메모를 페이지별로 찾아 이동·수정한다. 현재 선택한 글자를 새 메모 초안으로 가져올 수 있다. 새 메모는 연한 배경·짙은 글자와 내용에 맞는 높이를 사용한다. 긴 내용은 편집기로 다시 열어 읽는다. 이전의 앱 메모 중 투명 배경·검은 글씨인 메모는 명시적으로 수정·적용하면 가독성을 복구하며 실행 취소는 원래 외형까지 복원한다.
- 메모는 PDF 주석이며 디스크에 남기려면 PDF를 저장한다. 별도 노트 파일을 자동으로 만들지 않는다. 기존 주석 편집 권한을 지켜 다시 연 메모의 삭제는 편집 모드에서 하거나 명시적으로 수정한 뒤 수행한다.
- 메모 목록·AI·플러그인 패널은 같은 PDF 뷰를 유지한다. 목록에서 같은 페이지의 다른 메모를 눌러도 그 메모를 화면 중앙으로 이동한다.
- 지우개: 획 전체/부분과 크기 2–48pt. Option 키를 누르는 동안 반대 방식으로 전환한다. 한 번의 드래그는 한 번의 실행 취소/다시 실행이다. 부분 지우기는 PDF 픽셀을 덮어 가리는 방식이 아니라 잉크 선을 잘라낸다. 일반 네이티브 잉크와 새 필압·반투명 필기를 지원한다. 해석할 수 없는 이전 스탬프나 이미지·서명은 부분 지우기로 삭제하지 않는다.
- 펜: 굵기와 5–100% 불투명도. 반투명 필기 전체를 한 투명도 레이어로 그려 선분 이음새의 농도가 진해지는 현상을 방지한다. 새 필압·반투명 필기는 제한된 선 데이터도 저장해 재열기 후 부분 지우기를 지원한다. 이 메타데이터는 기하 정보이며 임의 주석 편집 권한을 주지 않는다.
- 선택: 텍스트 PDF/OCR 글자는 기존의 글자 선택. 이미지뿐인 페이지는 일반 드래그로 영역의 글자를 Mac에서 인식한다. 임시 선택이므로 원본 PDF에 OCR 텍스트를 추가하지 않는다. PDF 전체의 검색 가능한 텍스트를 저장하려면 OCR의 페이지 범위와 적용 결과를 확인한다.
- 새 안내 문구 28개를 지원하는 열 개 언어에 번역했다.

## 실제 파일 조사

사용자가 지정한 Halo PDF는 196페이지다. 원본에는 텍스트 레이어가 없고, `-ocr` 사본에는 조사 당시 9페이지만 텍스트가 있었다. 그 페이지의 PDFKit 네이티브 글자 선택은 읽기 전용 재현에서 정상 동작했다. 사용자 앱의 현재 탭은 원본 파일이었다. 사용자 PDF를 수정하지 않았다.
