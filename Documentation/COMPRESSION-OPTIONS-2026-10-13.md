# 이미지 품질 선택과 PDF 용량 줄이기 — 2026-10-13

EmberPDF 0.9.0 build 63은 사진을 넣기 전에 품질과 예상 용량을 확인하고 승인하도록 한다. 현재 PDF를 줄이는 기능은 별도의 미리 계산·사본 저장 흐름으로 제공한다.

## 사용 방법

- **이미지 삽입:** 편집 모드의 삽입 메뉴 또는 이미지 파일 드롭 → 원본 우선·균형·작은 용량 선택 → 이미지 미리보기, 픽셀 크기, 원본 파일 크기와 예상 PDF 증가량 확인 → 이미지 넣기. 여러 이미지는 한 번에 승인하고 한 번의 실행 취소로 되돌린다. 준비 중 또는 취소 시에는 PDF에 추가하지 않는다.
- **현재 PDF 압축:** 파일 → PDF 용량 줄이기… 또는 편집 도구의 페이지 메뉴 → 높은 품질·균형·작은 용량 선택 → 용량 미리 계산 → 현재 크기·결과 크기·감소량 확인 → 사본 저장. 결과가 더 작을 때만 저장할 수 있다. 저장 위치 창을 취소하면 계산 결과로 돌아간다.

품질 선택은 이번 작업에만 적용하며, 사진 삽입은 원본 우선, PDF 압축은 높은 품질을 기본으로 한다. 용량 계산은 Mac 내부의 백그라운드 작업으로 실행한다. 원본 PDF 파일과 열려 있는 문서의 변경 사항·실행 취소 기록은 사본 저장으로 바뀌지 않는다. 아직 저장하지 않은 편집 내용도 압축 사본에 포함한다.

## 품질과 크기

| 작업 | 원본 우선 / 높은 품질 | 균형 | 작은 용량 |
| --- | --- | --- | --- |
| 사진 삽입 | 호환 JPEG 압축 데이터 재사용, 기존 디코딩 크기 예산 유지 | 최대 변 2,400px, JPEG 품질 0.85 | 최대 변 1,600px, JPEG 품질 0.65 |
| PDF 압축 | 이미지 300dpi, 최대 변 6,000px, JPEG 품질 0.90 | 이미지 150dpi, 최대 변 3,200px, JPEG 품질 0.75 | 이미지 96dpi, 최대 변 2,000px, JPEG 품질 0.55 |

JPEG 품질 값은 인코더 설정이며 원본 화질의 백분율이 아니다. 사진 재압축과 축소는 선택에 따라 질감·세부 표현을 바꿀 수 있다. 이미지 삽입의 예상 증가량은 저장과 같은 이미지 그리기 경로를 사용한 추정값이다. 실제 PDF 구조에 따라 차이가 생긴다. 이미 압축된 작은 JPEG를 다시 인코딩했을 때 더 커지면 기존 표현을 유지한다. 투명한 삽입 이미지는 JPEG로 평탄화하지 않으며, 선택에 따른 크기 조정 후 투명 픽셀을 유지한다.

‘원본 우선’도 기존의 파일·픽셀 제한을 유지한다. 효율적 렌더링은 최대 변 3,200px·600만 픽셀, 일반 설정은 4,096px·1,200만 픽셀이다. 큰 파일은 축소될 수 있으며 실제 적용 크기를 승인 전에 표시한다. 여러 이미지 미리보기는 합계 4,800만 픽셀로 제한한다.

## 내용 보존

PDF 압축은 Quartz의 이미지 필터를 사용한다. 텍스트와 벡터 도형을 페이지 전체 이미지로 바꾸지 않아 글자 검색·선택을 유지한다. Quartz가 기존 주석의 이미지 스트림을 압축하지 않는 문제는 EmberPDF 이미지 주석의 표시 내용만 별도로 최적화하여 처리한다. 주석의 위치·겹침 순서·이미지 편집 식별자를 유지하며, 자르기로 제거된 원본 픽셀을 복원하지 않는다.

압축 전후 페이지 수·회전·페이지 상자·텍스트·주석·폼 값·링크·목차를 검사한다. 암호화·디지털 서명·접근성 태그·첨부 파일·레이어 등 보존을 확인할 수 없는 특수 구조는 처리하지 않는다. 최대 입력은 512MiB·10,000페이지다. 취소는 계산 전후와 페이지 사이에 확인한다. 이미 실행 중인 Quartz 내부 쓰기는 즉시 중단되지 않을 수 있지만, 취소한 결과가 다시 표시되거나 저장되지는 않는다.

저장은 미리 계산한 PDF 바이트를 그대로 별도 위치에 기록한다. 원본 경로뿐 아니라 원본을 가리키는 심볼릭 링크·하드 링크도 덮어쓰지 않는다. 저장 대상을 임시 파일로 검증한 후 교체하며, 원본 경로에 덮어쓰는 대체 동작은 없다.

## 구현 위치

- `ImageInsertionOptions`, `ImageInsertionPreparation`, `ImageInsertionOptionsSheet`: 품질 설정·불변 미리보기·예상 용량·삽입 승인.
- `PDFWorkspaceState+Compression`: 문서 사본 준비·요청 수명·정확한 결과 바이트 저장.
- `PDFCompressionService`, `PDFCompressionPresentation`, `PDFCompressionSheet`: 압축·보존 검사·백그라운드 취소·실제 용량 비교.
- 도구줄·Finder 드롭·파일 메뉴의 기존 진입점을 위 흐름으로 연결한다.

## 검증

최종 XCTest는 **151개 통과, 실패 0**이다. 모델·서비스 회귀 126개, 이미지 상호작용 24개, 실제 화면 렌더링 1개를 별도 실행했으며 중복 합산하지 않았다.

- 핵심 회귀 로그: 품질별 크기, 투명 픽셀, 기존 JPEG 보존, 명시적 삽입 승인·취소·일괄 실행 취소, 미리보기 이후 파일 변경, 문서 전환·수정, 혼합 파일 드롭의 대상 탭, PDF 압축 후 텍스트·도형·폼·링크·주석·목차, 정확한 사본 바이트, 원본 및 원본 링크 보호를 검사했다.
- 이미지 상호작용 로그: 기존 이미지 편집 회귀 24개.
- 화면 검사 로그: 한국어·영어 × 밝음·어두움에서 두 선택창을 530pt 너비로 실제 렌더링했다. 높이는 458~514pt로, 이미지·설명·버튼이 잘리지 않고 표시된다. PNG 8개.
- 정적 검증: 버전 0.9.0 (63), 10개 언어 키·문자열 검사 통과.

마지막 행의 측정 JSON, 압축 전 PDF, 균형 PDF를 보존했다. 압축 전 이미지와 균형 이미지를 1224×1584로 렌더링하여 사진의 위치·방향·색 배치를 확인했다. 균형 결과는 고운 질감이 일부 부드러워지며, 무손실 결과라고 주장하지 않는다. 재개방 후에도 사진 주석 1개가 편집 가능한 상태로 남는다.

검사는 합성 이미지와 PDF로 실행했다. 모든 외부 PDF가 같은 비율로 줄어들거나 모든 특수 구조를 지원한다는 보증은 아니다.
