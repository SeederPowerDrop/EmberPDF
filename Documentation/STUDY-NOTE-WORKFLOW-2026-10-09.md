# 메모 작성·연결 화면 — build 35

EmberPDF 0.9.0 build 35의 로컬 변경입니다. 공개 GitHub Release는 포함하지 않습니다.

## 작성 화면

- 도킹/별도 창 버튼을 메모 제목·페이지와 같은 줄에 배치했습니다. 분리된 버튼 행과 큰 제목 장식을 줄이고 본문 작성 공간을 확보합니다. 별도 창에서 옆에 붙이기로 돌아와도 같은 초안을 유지합니다.
- `주석 내용` 옆의 인용·시계·문서 아이콘은 현재 선택 글자, 현재 날짜와 시각, 현재 PDF 파일명과 페이지/전체 쪽수를 넣습니다. 시각은 사용자의 지역·시간대 형식을 따릅니다. 위치는 메모가 처음 만들어진 쪽이 아니라 버튼을 누를 때 읽고 있는 쪽입니다.
- 삽입은 편집기의 커서 위치에 이루어지며 선택 범위가 있으면 교체합니다. 실행 취소/다시 실행과 기존 길이 제한을 적용합니다. 한글 등 입력기 조합 중에는 삽입하지 않습니다.
- PDF 글자 인용은 현재 문서에 속한 선택인지와 복사 권한을 확인합니다. 클립보드를 사용하지 않습니다. 메모 시작 후 선택 도구로 전환하여 PDF를 다시 드래그할 수 있게 하고, 후속 클릭이 기존 초안을 덮어쓰지 않게 했습니다. 편집기 갱신이 PDF에서 포커스를 다시 빼앗지 않도록 변경했습니다.
- 적용 전에는 PDF 내용이나 변경 상태를 수정하지 않습니다. 기존 초안 분리·페이지별 메모 캐시를 유지합니다.

## 연결 화면

- 메모 모양과 연결 팝오버를 각 메모 행의 버튼에 붙였습니다. 연결 창은 클릭한 메모 옆에서 열리고, 긴 목록은 창 안에서 스크롤합니다.
- 페이지 입력은 입력 중의 문자열을 그대로 유지하며 전체 쪽수 범위에 맞는 경우에만 연결합니다. 숫자를 모두 지우거나 두 자리 이상 입력하는 과정에서 1로 되돌리지 않습니다.
- 선택한 열린 PDF의 실제 문서와 변경 상태를 관찰하고, 휴면 탭은 해당 문서만 불러옵니다. 메모는 전체 페이지에서 찾고 PDF에 저장된 책갈피와 함께 선택할 수 있습니다. 파일 접근 실패, 빈 목록, 검색 진행 상태를 표시합니다.
- 책갈피 연결은 해당 책갈피의 페이지로 이동합니다. PDF 외부 파일이나 웹 주소를 실행하는 책갈피는 대상 목록에 포함하지 않습니다. 별도 사용자 책갈피 저장 기능을 새로 추가한 것은 아닙니다.
- 연결은 기존과 같이 이 Mac의 앱 내부 목록에 저장됩니다. 메모 연결을 위해 식별자가 새로 추가되면 PDF도 저장해야 유지됩니다. 다른 앱/기기에 관계 목록을 내보내지는 않습니다.

## 검증

- 통합 검사 159개 통과. 실제 화면 점검에서 발견한 도킹 중 SwiftUI 해제 알림 충돌을 고친 뒤, 새 회귀 2개를 포함한 편집기·초안·선택 연속성·성능 검사 54개를 다시 통과했습니다. 중복을 제외하면 서로 다른 161개 검사입니다. 로그는 `work/study-build35/tests.log`, `editor-lifecycle-tests.log`입니다.
- 도킹 충돌은 편집기 해제 중 observable 알림이 SwiftUI 그래프에 다시 들어가는 원인이었습니다. 해제 시 알림을 보내지 않고, 입력기 조합 변경 알림을 다음 이벤트로 지연하며 이전 편집기의 알림을 취소합니다.
- 2쪽 원본 역할 PDF와 15쪽 대상 PDF를 만든 별도 QA 앱에서 날짜·시각·현재 파일/페이지 삽입, 작성 중 PDF 본문 드래그·인용을 확인했습니다. 1쪽에 만들기 시작한 메모에서 2쪽으로 이동한 뒤 위치 버튼을 누르면 `2/2페이지`가 삽입됩니다.
- 별도 창→도킹, 별도 창 닫기→도킹, 별도 창에서 적용을 확인했습니다. 한글 초안과 삽입한 내용이 유지되고 합성 PDF에 저장됩니다. 사용자 원본 PDF는 수정하지 않았습니다.
- 12쪽을 직접 입력해 연결·이동했습니다. 다른 PDF 전체 목록의 9쪽/14쪽 메모와 4쪽/12쪽 책갈피를 확인하고, 14쪽 메모와 4쪽 책갈피를 연결했습니다. 필터로 숨긴 이전 선택에 연결할 수 없음을 확인했습니다. 책갈피 연결에서 4쪽으로 이동하는 것을 확인했습니다.
- 연결 팝오버는 각 메모 행의 실제 버튼에 귀속됩니다. 내용은 단일 스크롤 영역으로 제한하여 높이 변경 시 선택기 상태를 다시 만들지 않습니다.
- 정적 검증과 10개 언어 번역 검사, `git diff --check` 통과. ZIP 생성 시 앱/내부 구성요소 서명 및 압축 재검증 통과.
