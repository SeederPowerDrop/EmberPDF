# 드래그 후 본문 직접 편집 — 2026-10-14

대상 소스: **EmberPDF 0.9.0 (build 68) Developer Preview**

상태: **관련 XCTest 192개·정적 검사·Release 패키징 검증 통과**. 선택한 단어가 유지되는 페이지 편집 화면과 밝은·어두운 글자 대비를 렌더링해 확인했습니다. 사용자 PDF를 직접 조작하는 수동 검증은 하지 않았습니다.

## 사용 흐름

편집 모드에서 **선택** 도구로 본문의 원하는 글자를 드래그합니다. 마우스를 놓으면 같은 글자 범위가 선택된 텍스트 편집기로 이어집니다. 다시 도구를 누를 필요 없이 입력하면 선택한 문구를 바꾸고, Delete로 선택한 글자만 지울 수 있습니다. 편집 대상 텍스트의 앞뒤 문자는 유지합니다. 단어를 더블클릭한 경우에도 선택된 단어를 바로 편집합니다.

상단 **PDF 텍스트**의 표시 이름은 **텍스트 추가**로 변경합니다. 빈 곳에 새 글을 넣을 때 이 도구를 사용합니다. 기존 본문 수정의 기본 흐름은 선택 도구의 드래그입니다.

| 조작 | 동작 |
| --- | --- |
| 드래그 후 입력 | 선택한 글자를 입력한 내용으로 교체 |
| 드래그 후 Delete | 선택한 글자 삭제 |
| Return | 줄바꿈 |
| 다른 곳 클릭 또는 ⌘Return | 편집 적용 |
| Esc | 현재 편집 취소 |
| ⌘C·⌘V·⌘Z | 편집 중에는 macOS 텍스트 편집기의 복사·붙여넣기·실행 취소 |

보기·학습·비교 화면은 선택·복사 동작을 유지합니다. Option 드래그로 만든 선택도 자동 편집 전환에서 제외합니다.

## 선택 범위와 원문 보존

- 선택된 문자열뿐 아니라 각 줄의 글자 위치를 함께 대조합니다. 옆 그림 설명이나 다른 위치의 같은 단어를 편집 대상으로 대신 사용하지 않습니다.
- 단일 텍스트 객체 안의 부분 선택은 원래 문자열과 UTF-16 선택 범위를 편집기에 전달합니다. 첫·마지막 객체에 있는 선택하지 않은 앞뒤 문자를 함께 유지합니다.
- 서식과 줄 배치가 맞는 연속 텍스트 객체는 하나의 편집 대상으로 묶습니다. 서로 다른 서식이나 중간에 다른 도형이 끼는 등 안전하게 합칠 수 없는 경우에는 전체 선택을 유지하고 편집기로 전환하지 않습니다.
- 드래그 중에는 기존 선택 표시만 갱신합니다. 편집 대상 검사와 편집기 구성은 마우스를 놓은 뒤 수행합니다.
- 초안을 여는 것만으로 PDF를 변경하지 않습니다. 변경 없이 닫기·취소는 문서를 수정 상태로 만들거나 실행 취소 기록을 추가하지 않습니다.
- 적용은 원본 페이지를 재확인한 뒤 분리된 페이지 사본에서 준비합니다. 성공한 변경은 하나의 페이지 교체 기록으로 관리하고, 실행 취소로 기존 페이지와 주석을 복원합니다. 적용 실패 시 원본 페이지와 편집 초안을 유지합니다.

## 지원 구조와 한계

편집 가능한 네이티브 PDF 텍스트가 대상입니다. 같은 글꼴·크기·색상, 호환되는 수평 배치와 줄 간격을 가진 연속 객체·여러 줄을 지원합니다. PDF 내부 객체의 순서와 변형, Form 구조 및 그리기 순서를 확인하며, 지원하지 않는 구조를 선택했을 때 일부 글자만 임의로 수정하지 않습니다.

스캔 이미지의 OCR 선택, 서로 다른 서식이 섞인 선택, 여러 페이지에 걸친 선택, 특수 변형·클리핑·공유 Form 등 편집 엔진이 안전하게 처리할 수 없는 구조는 일반 선택·복사로 남을 수 있습니다. 기존 자유 텍스트 주석은 주석 편집 경로를 사용합니다. 문서 편집 권한 검사도 유지합니다.

Word 문서처럼 PDF 전체의 문단·표·페이지가 자동으로 재배치되는 기능은 아닙니다. 호환되는 선택 대상 안에서 텍스트를 수정하며, 사용 가능한 글꼴에 따라 원본과 글자 모양·간격이 달라질 수 있습니다. 페이지 밖으로 넘치는 편집은 적용하지 않고 초안을 유지합니다. 모든 PDF에서 드래그한 문구가 편집 가능하다고 보장하지 않습니다.

## 검증 결과

- 최종 관련 XCTest **192개 통과, 실패 0**. 로그: `work/direct-edit68/regression-tests-final.log`.
- 본문 엔진·선택 매핑·워크스페이스·초안 수명·파일 크기·직접 마우스 이벤트·선택 미리보기·편집기·모드·키보드·학습 메모·도움말·현지화 검사를 포함합니다. 실제 PDF를 임시 생성해 수정, 저장, 재열기, 실행 취소와 원문 보존을 검사합니다.
- 드래그 중 편집기가 열리지 않고 마우스를 놓은 뒤 같은 UTF-16 범위를 넘기는 것, 입력/삭제 시 앞뒤 문자를 보존하는 것, 한글 조합과 이모지, 반복 편집, 지원하지 않는 선택 유지, 다른 모드에서 편집하지 않는 것을 확인합니다.
- 최초 실행에서 PDFium의 텍스트 객체 경계 공백 중복 반환과 IME 확정 시 조합 범위 대신 커서 범위를 사용하는 문제를 발견해 수정했습니다. 추가 회귀에서 점 클릭으로 초안을 열기 전에 도구를 바꿔야 하는 순서 문제도 수정했습니다. 기존 현지화 검사의 Bitcoin 고유명과 프랑스어 동형어 오탐은 해당 키/값에 한정해 예외를 명시했습니다.
- 실제 페이지 위 편집기의 선택 문구 1개, 밝은/어두운 화면의 검정/흰 글자 조합 4개를 AppKit에서 렌더링했습니다. `work/direct-edit68/screens/`에 보관합니다. 설치 앱을 사용자가 직접 조작한 검증과는 구분합니다.
- 프로젝트 정적 검사와 10개 언어 키 일치 검사 통과. 로그: `work/direct-edit68/static-validation.log`.
- 사용자 원본 PDF를 편집·저장하는 수동 검증이나 PDF Expert와의 성능 비교는 하지 않았습니다. 이번 검사는 위 자동 fixture 및 화면 렌더링 범위입니다.

드래그 중에는 PDFium을 호출하지 않습니다. 마우스를 놓은 뒤 선택 문자를 검사할 때 UTF-16 길이 누적, 객체별 문자 인덱스 재사용, 한 번의 객체 경로 순회를 사용해 반복적인 전체 페이지 탐색을 줄였습니다.
