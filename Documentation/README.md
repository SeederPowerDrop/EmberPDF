# EmberPDF 문서 지도

> 최신 저장 보호 확인 결과는 [품질 검사 기록](QUALITY_REPORT.md)을 참고하세요.

문서가 많아질수록 “어떤 파일이 최신 기준인지” 찾기 어려워집니다. 목적에 맞는 시작점을 아래에서 고르세요. 기능 설명이 서로 다르면 현재 코드와 테스트, `PRODUCT.md`, `ARCHITECTURE.md` 순으로 근거를 확인하고 불일치를 Issue로 남깁니다.

현재 소스 문서 기준은 **EmberPDF 0.9.0 (build 90) Developer Preview**입니다. 앞선 화면 변경은 [2026-10-05 Ember 디자인](EMBER-DESIGN-2026-10-05.md), 페이지 번역 검증은 [2026-10-05 페이지 번역](PAGE-TRANSLATION-2026-10-05.md), 앞선 누적 정리는 [2026-10-01 소스 갱신](SOURCE-UPDATE-2026-10-01.md)에 있습니다. 차분한 홈·읽기 화면, 패널 크기에 맞춰 커지는 썸네일, 방향키 속도와 OCR·선택·번역 개선, Swift·Rust 학습 자료를 포함합니다. 마지막 GitHub Release 다운로드 배포본은 **0.8.0 (build 18)**이며, 소스 갱신은 새 Release 자산 공개를 뜻하지 않습니다. [9월 22일 로컬 패키지](RELEASE-VALIDATION-0.9.0.md)와 [9월 23일 이름 통일 기록](SOURCE-UPDATE-2026-09-23.md)의 검사 수·체크섬은 당시 기준으로 보존합니다.

## 사용자와 기여자

**build 85 (2026-10-18)**의 비동기 전체 저장 보완과 최종 자동 검증은 독일 경기장 책 저장 후속 수정에 정리합니다. 고유 회귀 2,116개 중 2,096개 통과·20개 건너뜀·실패 0개, 추출·병합 61개 비동기 재저장과 외부 픽셀 270/270 일치, 별도 357쪽 전체 픽셀 일치를 확인했습니다. 패키지 검증·설치와 실제 앱 4권·8개 저장본의 외부 검사도 통과했습니다. 작업 공간 3개·탭 26개·문서 24개와 설정을 유지해 재실행했으며, 본문 적용 8.245초와 원시 태그 비교의 남은 제한도 구분합니다.

**build 84 (2026-10-18)**의 대형 태그 PDF 비동기 저장, 원래 그리기 명령·소수 페이지 경계 보존과 최종 자동 검증 결과를 확인했습니다. 고유 회귀 2,114개 중 2,094개 통과·조건부 20개 건너뜀·실패 0개이며, 실제 추출·병합 출력 61개의 비동기 저장과 외부 픽셀 270/270 일치를 확인했습니다. 추가 전체 책 저장 실패와 설치 실행 파일 변경을 발견해 build 84 완료 판정을 보류했습니다.

**build 83 (2026-10-18)**은 실제 앱 저장에서 누락되던 비표준 URI를 보존합니다. 전체 회귀 2,050개 통과·17개 조건부 건너뜀, 실제 30개 PDF 병합·추출과 설치 앱 3권·6개 저장 단계를 검증했고 기존 설정·문서를 유지해 실행했습니다. 최종 검증과 제한

**build 82 (2026-10-18)**의 실제 앱 검증 후속 수정을 적용했습니다.

**build 81 (2026-10-18)**의 여러 곳 편집 서식·저장 기록 확인·내용 스트림 경계 보존을 적용했습니다.

**build 80 (2026-10-18)**의 원문 한자 선택과 본문 추출 순서 보존을 검증했습니다.

**build 79 (2026-10-17)**는 제보된 스캔 PDF의 여러 줄 편집과 미리보기 시작 시 화면 멈춤을 수정합니다. 실제 184쪽 드래그·입력·저장·재열기, 10개 언어 전환과 전체 회귀 1,936개 통과·조건부 19개 건너뜀은 수정 기록에 있습니다.

**build 78 (2026-10-17)**의 병합·추출 구조 보존 확장과 PDFKit 중단 조사는 [후속 검증 기록](PDF-STRUCTURE-PRESERVATION-2026-10-17.md)에 있습니다.

**build 77 (2026-10-17)**은 본문 원형·병합·추출 보존과 함께 보기의 **본문 변경점** 비교를 추가합니다. 외부 엔진·실제 PDF·10개 언어 검증 범위는 [통합 검증 기록](PDFCRAFT-INTEGRATION-2026-10-17.md)에 있습니다.

**build 76 (2026-10-17)**의 **문장 드래그 → 본문 편집(가T) → 입력** 흐름과 OCR 스캔 편집 범위는 [선택한 본문 편집 기록](SELECTED-TEXT-EDITING-2026-10-17.md)에 있습니다. 관련 XCTest 337개 통과·3개 건너뜀, 실제 NEWTON 164쪽 저장·재열기와 별도 Release 패키지 검증을 마쳤습니다. 설치 앱은 동시 작업을 위해 유지했습니다.
