# 새 탭 홈 화면 — 2026-10-08

버전: **EmberPDF 0.9.0 (build 31)**

## 동작

탭 막대의 **+**는 파일 선택 창 대신 새 EmberPDF 홈 탭을 만들고 선택한다. 기존 **⌘T**와 같은 모델 경로를 사용한다. 홈에서 **PDF 또는 이미지 열기…** 또는 **⌘O**를 선택하면 파일 선택 창이 열린다. 기존 탭 메뉴의 파일 열기 항목은 유지한다.

홈은 사용자가 고른 앱 아이콘을 88pt로 표시하고 기존 철학 문구를 보여 준다.

> 잉걸불처럼 오래도록, 든든한 PDF 도구.
> 누구나 편하게 읽고 편집하는 PDF 뷰어·편집기

최근 PDF는 최대 7개를 표시한다. 항목을 누르면 다시 열고, 이미 열려 있는 파일이면 기존 탭을 선택한다. 새 파일은 활성 홈 탭을 재사용한다. 각 항목의 ×와 **목록 지우기**는 기록만 제거하며 원본 파일과 열린 탭은 유지한다. 기존 북마크와 기록 저장 구조를 재사용한다.

홈 하단에 **플러그인 관리…** 진입점을 추가한다. 기존 창 수명 확장의 호스트·명령·사이드바는 문서 화면 밖에서 유지되므로 홈에서도 동작한다. PDF가 필요한 작업의 권한과 문서 조건은 그대로 적용한다. 별도 홈 위젯 API를 추가한 것은 아니다. 필통과 트랙패드 필기는 사용자가 설명한 향후 아이디어이며 이번 구현에 포함하지 않는다.
