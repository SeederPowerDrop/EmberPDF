# 상하좌우 페이지 이동 — 2026-10-10

대상: EmberPDF 0.9.0 (build 42), macOS arm64.

## 변경

- 설정의 PDF 보기 조작 → 메인 페이지 이동 및 보기 메뉴에 ‘상하좌우 다 사용하기’를 추가했다. 기본값과 기존 두 옵션은 유지한다.
- 메인 PDF 화면에서 ↑/←는 이전, ↓/→는 다음 페이지로 이동한다. 2페이지 보기는 2장, 3–12페이지 보기는 해당 페이지 묶음씩 이동한다. 문서 시작·끝과 마지막 불완전 묶음을 안전하게 처리한다.
- 새 옵션은 키보드만 변경한다. 세로 페이지 배치, 마우스·트랙패드 동작과 확대·축소를 유지한다. 기존 세로 스크롤 옵션과 전환할 때 PDF 좌표와 확대율을 유지한다.
- 검색·메모·폼 입력란과 주석 편집기가 가진 방향키, Shift 텍스트 선택, Option/Command/Control 단축키를 가로채지 않는다. 함께 보기의 고정·동기 이동에는 기존 네이티브 방향키 처리를 유지한다.
- 10개 언어에 제목과 설명을 추가했다. 기존 저장 설정과 문서 복원 데이터를 유지한다.
