# 페이지 번역

EmberPDF의 현재 PDF 페이지를 번역해서 페이지 형태로 읽는 공식 플러그인입니다.
플러그인 관리에서 **페이지 번역**을 설치한 뒤, 보기·학습 모드의 PDF에서
**현재 페이지를 번역해서 보기**를 실행합니다. 원문과 대상 언어를 확인하고 번역하면
번역 페이지를 미리 볼 수 있습니다. 원본 PDF는 수정하지 않습니다.

- **macOS 번역**은 macOS 15 이상의 Apple 기기 내 번역을 사용합니다. 필요한 언어
  다운로드는 macOS에서 안내합니다.
- **외부 AI**는 앱에 설정한 공급자·모델·API 키를 사용합니다. 전송할 원문과 목적지를
  확인한 후에만 번역하며, 페이지 이미지나 PDF 파일 자체는 보내지 않습니다.
- **로컬 언어팩**은 이 Mac에서 실행 중인 Argos 번역 도우미를 사용합니다. 설치와
  실행 방법은 저장소의 `Documentation/LOCAL-TRANSLATION.md`를 참고하세요.

미리보기는 캡처한 한 페이지의 그림과 글 영역을 바탕으로 번역문을 배치합니다.
번역 길이와 원본 구조에 따라 글꼴·줄바꿈이 달라질 수 있으며, 복잡한 표·겹친 글자는
완벽하게 재현하지 못할 수 있습니다. 읽을 수 있는 텍스트가 없는 스캔 페이지는
먼저 OCR을 실행하세요. 페이지 번호는 실행 시점의 원본 페이지를 가리킵니다.
페이지의 글 영역과 번역문을 연결하기 위해 이 플러그인에서는 원문을 직접 수정하지
않습니다. 원문 수정이나 웹 번역 도우미가 필요하면 기존 **번역 도우미**
(TranslationCompanion)를 사용하세요. 기존 도우미의 기능과 설정은 유지됩니다.

현재 페이지 전체를 안전하게 처리할 수 없으면 실패 이유를 표시합니다. 텍스트를
몰래 잘라서 완성된 페이지처럼 표시하지 않습니다. 번역 페이지는 호스트가 만들며,
플러그인 패키지는 코드·스크립트를 실행하거나 원본 문서를 직접 변경하지 않습니다.
이 패키지는 앱 번들에 포함된 manifest와 정확히 일치할 때만 설치할 수 있습니다.
