EmberPDF 플러그인

PDF를 읽는 자리에서 번역하고, 노트를 쓰고, 복습 카드를 만들 수 있습니다. 필요한 도구를 골라 설치하거나, 앱을 다시 빌드할 필요 없이 나만의 기능을 추가할 수 있습니다.

기본 플러그인 별도 설치 예제 직접 만들기

1.0.0 기본 플러그인 13개

앱의 플러그인 → 플러그인 관리를 열고 EmberPDF 기본 플러그인에서 원하는 항목의 권한을 확인한 뒤 설치하세요. 아래 이름을 누르면 각 패키지의 공개 소스가 열립니다.

  • 페이지 번역

    현재 페이지의 배치 위에 번역문을 표시합니다.

  • 번역 도우미

    선택 문장이나 페이지를 검토한 뒤 번역 서비스에서 읽습니다.

  • Hover Translator

    마우스를 올린 단어를 Mac에서 번역합니다.

  • Markdown Notebook

    PDF 옆에서 로컬 노트나 Markdown 파일을 엽니다.

  • Page Clipper

    페이지의 일부를 잘라 PNG로 복사하거나 저장합니다.

  • Related Documents

    이미 열린 다른 PDF에서 관련 구절을 찾고 이동합니다.

  • 웹 브라우저

    PDF 옆 패널에서 검색하거나 공개 HTTPS 사이트를 엽니다.

  • Study Markup

    하이라이트와 밑줄 색상 프리셋을 적용합니다.

  • Tablet Tools

    태블릿이나 Sidecar 입력으로 필기할 때 학습 도구에 접근합니다.

  • Reading Navigation

    긴 문서에서 페이지를 이동하고 읽기 모드를 바꿉니다.

  • Reading Colors

    앱과 PDF 용지의 읽기 색상을 조정합니다.

  • Reading Lab · 독서 실험실

    페이지의 단어 빈도를 살펴보고 생각을 메모합니다.

  • Research Trail · 읽기 여정

    어떤 문서와 페이지를 읽었는지 기록합니다.

GitHub에서 받아 설치하는 예제 7개

1.0.0 소스 ZIP을 풀면 Examples/Plugins에 예제가 있습니다. 앱의 플러그인 관리 → 플러그인 설치에서 원하는 .hwattakplugin 폴더를 선택하세요.

  • Ember Recall · 복습 카드

    선택한 문장으로 로컬 질문·답 카드를 만들고, 답을 가려 복습합니다. 원문 탭이 열려 있으면 해당 페이지로 돌아갈 수 있습니다.

  • Hello Ember

    명령, 버튼이 있는 패널, 창마다 유지되는 카운터를 만드는 첫 JavaScript 예제입니다.

  • Community Starter

    하이라이트, 밑줄, 펜, 학습 모드와 페이지 이동 명령을 한곳에 모읍니다.

  • Offline Checklist

    문서 내용이나 네트워크 접근 권한 없이 학습 체크리스트를 보여줍니다.

  • Markdown Quote

    선택 구절과 페이지 번호를 Markdown 인용문으로 복사합니다.

  • Quick Citation

    짧은 인용을 표시하거나 복사하고, 사용자 확인 후 선택문을 웹에서 검색합니다.

  • Reference Search

    사용자 확인 후 선택 문장을 Wikipedia 또는 Google Scholar에서 검색합니다.

YouTube Study는 PDF를 읽으면서 학습 영상을 보는 아이디어를 담은 검토용 소스입니다. 1.0.0에서는 이 예제를 설치할 수 없습니다.

직접 만들기

선택한 글을 복사하거나 검색을 열어 주는 간단한 기능은 manifest.json에 동작을 정의하면 됩니다. 고유한 명령·화면·저장 기능이 필요하다면 JavaScript로 구현할 수 있습니다.

  1. Hello Ember 예제 폴더를 복사해 MyExtension.hwattakplugin으로 이름을 바꿉니다.
  2. manifest.json에 고유한 identifier, 표시 이름, 작성자와 기능에 필요한 권한을 적습니다.
  3. main.js에서 EmberPDF가 제공하는 API로 명령과 창 안의 화면을 만들고, 코드가 바뀔 때마다 shasum -a 256 main.js 결과를 runtime.sha256에 반영합니다.
  4. 플러그인 관리에서 폴더를 설치한 뒤 ⇧⌘P로 명령을 실행해 확인합니다.
