EmberPDF 1.0.0 · build 91

첫 정식 버전

저장 보조 프로세스의 상태를 일시적으로 읽지 못하면 다시 확인하도록 수정했습니다. 357쪽 태그 PDF로 저장·재열기와 취소를 확인했고, 마운트 및 서명 검증을 마친 DMG를 공개했습니다. 검수용 사본에서 Finder로 실행해 PDF가 표시되는 것도 확인했습니다.

전체 XCTest 2,788건에서 2,754건이 통과했고 33건은 조건부로 건너뛰었습니다. 직접 저장한 PDFKit 글꼴의 권한 정보에 관한 기존 진단 1건이 실패했습니다. 앱의 저장 경로로 같은 글꼴을 두 차례 저장·재열기하는 검사는 통과했습니다.

EmberPDF 0.9.0 · build 90

편집한 페이지와 대형 PDF 저장 검증

본문을 편집한 페이지에서 원본 접근성 태그 연결을 보존할 수 없는 경우 저장을 중단하도록 보완했습니다. 여러 문서 구조를 비교하고, 실제 PDF 30종의 추출·병합과 결과 61개의 비동기 재저장을 검증했습니다.
